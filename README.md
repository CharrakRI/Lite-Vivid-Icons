# Lite-Vivid-Icons
**A fix for icons breaking when Vivid-Dark-Icons theme is used on Linux Lite.**
- When the Vivid-Dark-Icons theme is used on Linux Lite, some of the native application icons break and some of the sizes are too large compared to normal.
- To fix these, this updated version contains a hybrid theme consisting of both the Vivid icons and some icons from within Linux Lite.
- Also edited index.theme for sizes. Not done by AI.
